# 3kW Electric Go-Kart

Converted kart: 3kW motor + [72V pack I built](../gokart-battery-pack/README.md). ~$50 controller, ~$100 motor, ~$200 second-hand frame.

[Frame and motor video](media/kart-frame-and-motor.mp4)
[First test ride video](media/first-test-ride.mp4)

## Notes

- Controller: badly documented "activation code" sequence; nearly gave up, got working next day.
- Battery box: wooden (no fibreglass), yoga-mat padding to prevent sliding; phone Bluetooth cutoff for safety.
- Frame: poor build — falling bearings, non-working brakes (fixed lines/pads), stanced stance making steering hard.
