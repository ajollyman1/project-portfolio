# Line-Following Robot

ENMT221 Mechatronics Design 1, UC (Sem 2, 2026). Team placed 2nd.

## My part

Microcontroller section of the team LFR PCB:
- ATmega4808-A with regulator, decoupling, clock
- Connectors for sensors, motor drivers, battery, programming headers
- KiCad layout + Gerber/drill files

Team merged sections into one board, programmed (line sensing → PWM), raced.
