# phone-ui

A small installable **PWA** that acts as the front-end for [`phone-mcp`](../phone-mcp/README.md) — because controlling my phone by curling an MCP server is technically fine and practically miserable.

It's a static site with a service worker so it installs to the phone's home screen and works offline as a shell. From it I can see the phone, take a screenshot, run quick actions, and hit the **kill switch** without having to find a terminal. When my agent's off doing something I didn't expect, that kill switch being one thumb-tap away is the whole point.
