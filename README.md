# Project Portfolio

Things I've built — software (self-hosted homelab + agent tooling, incl. a Jarvis-style local AI assistant) and hardware (e-kart / e-bike / battery).

## Software, AI & self-hosting

- **[homelab](homelab/README.md)** — Linux server: local LLMs/speech, Docker Compose, Caddy, netbird, KVM, Jellyfin/*arr media stack.
- **[phone-mcp](phone-mcp/README.md)** — LLM agent drives an Android phone over ADB (MCP). No shell, kill switch, loopback-only. Includes phone-ui PWA front-end. Ongoing.
- **[voiceapi](voiceapi/README.md)** — OpenAI-compatible STT+TTS API, all local models.
- **[calendar-mcp](calendar-mcp/README.md)** — CalDAV calendar as MCP tool with write-verification.

## Hardware

- **[homemade-spot-welder](homemade-spot-welder/README.md)** — spot welder from car battery + MOSFETs. Unreliable but worked.
- **[gokart-battery-pack](gokart-battery-pack/README.md)** — 72V 20S10P pack from recycled 18650 cells (~$250 vs $600–1000).
- **[go-kart](go-kart/README.md)** — converted 3kW electric go-kart.
- **[first-ebike](first-ebike/README.md)** — 36V/500W mid-drive e-bike conversion.
- **[lfr](lfr/README.md)** — line-following robot; designed ATmega4808 PCB; team 2nd.
